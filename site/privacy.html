Privacy Policy

PDF Toolbox is built to process files locally on your device.

File processing

PDF Toolbox does not upload your files. PDF operations run on your computer using bundled local processing components.

Data collection

PDF Toolbox does not collect documents, passwords, file paths, usage analytics, crash telemetry, or personal information.

Passwords

Passwords entered for PDF protection or unlocking are used only for the selected operation. They are not saved by the application.

Update checks

The application includes an optional manual update check. When used, it contacts GitHub to compare the installed version with the latest public release.
