Free offline PDF tools

PDF Toolbox is a single downloadable desktop app for everything you need: merging, splitting, compressing, converting images, and managing passwords. Fully offline, with no sign-ups or limits.

Download PDF Toolbox Read privacy policy

Also available for: Windows, Mac (Universal), Linux (.deb), or All versions.

Free, permanently.

PDF Toolbox is free and will always be free. There is no subscription, no usage limit, no locked basic feature, and no required account.

Included tools

Organize

Merge PDFs, split files, reorder pages, extract pages, remove pages, and rotate pages.

Convert

Create PDFs from images or export PDF pages as PNG, JPEG, or WebP images.

Optimize

Compress PDF files and remove document metadata.

Security

Add password protection or unlock PDFs when you know the password.

Private by design

Files are processed locally. PDF Toolbox does not upload documents, passwords, file paths, or usage data. The optional update check only contacts GitHub to see whether a newer release is available.
