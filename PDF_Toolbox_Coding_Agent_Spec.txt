0. CORE OPERATIONAL DIRECTIVES FOR AI AGENTS (MANDATORY RULES)
======================================================================
1. SCOPE INTEGRITY: Do NOT change product scope. Do NOT add OCR, full PDF text editing, cloud sync, or user accounts.
2. NO CLOUD / NO TELEMETRY: 100% offline document processing. Never transmit file names, paths, or document content over the network. Core operations must function with network interfaces disabled.
3. ARCHITECTURE LOCK: Use Tauri 2 + Rust backend. Do NOT switch to Electron, Java, Spring Boot, or local HTTP servers.
4. ENGINE DISCIPLINE:
   - Rendering, Thumbnails, PDF -> Image, Text Extraction: Use PDFium.
   - Structural manipulation (Merge, Split, Extract, Reorder, Rotate, Delete, Passwords, Lossless metadata): Use qpdf.
   - Direct Image -> PDF: Native PDF generation layer (embed original JPEG streams directly without recompression).
5. NON-DESTRUCTIVE & ATOMIC WRITING: Never overwrite source files by default. Always write output to `.tmp.[uuid]` files first, verify integrity, and atomically rename/move to final destination.
6. NO FAKE PROGRESS / STUBS: Never present stubbed or mock progress bars as complete implementations. Long-running jobs must report real per-page/per-file progress and support cancellation.
7. MEMORY SAFETY & BOUNDED CACHING: Never load entire large documents into memory as uncompressed bitmaps. Use page-by-page streaming and bounded thumbnail caches. Idle memory must remain < 100MB.
8. ZERO-DEPENDENCY REASONING: Keep external dependencies strictly audited (MIT, BSD, Apache-2.0). Maintain THIRD_PARTY_LICENSES.md.

3.2 Job Models (src-tauri/src/jobs/model.rs):
```rust
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct JobId(pub String);

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum JobStatus {
    Queued,
    Running { current_step: u32, total_steps: u32, message: String },
    Completed { output_paths: Vec<PathBuf> },
    Failed { error: String },
    Cancelled,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum ConflictResolution {
    AutoRename,
    Overwrite,
    Skip,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct OutputConfig {
    pub output_directory: PathBuf,
    pub filename_template: String, // e.g., "{name}_processed.{ext}"
    pub on_conflict: ConflictResolution,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", content = "payload")]
pub enum OperationPayload {
    PdfToImages {
        input_pdf: PathBuf,
        format: ImageFormat, // Jpeg, Png, Webp
        dpi: u32,
        quality: u8,
        page_range: Option<String>,
    },
    ImagesToPdf {
        input_images: Vec<PathBuf>,
        page_size: PageSizeOption, // FitImage, A4, Letter, Custom
        margins_pt: f32,
        direct_jpeg_passthrough: bool,
    },
    Merge {
        input_pdfs: Vec<PathBuf>,
    },
    Split {
        input_pdf: PathBuf,
        mode: SplitMode, // EveryNPages(u32), PageRanges(Vec<String>)
    },
    Extract {
        input_pdf: PathBuf,
        page_range: String,
        single_output: bool,
    },
    Reorder {
        input_pdf: PathBuf,
        page_order: Vec<u32>, // 1-indexed new page mapping
    },
    Rotate {
        input_pdf: PathBuf,
        rotation_degrees: i32, // 90, 180, 270
        scope: PageScope,     // All, Even, Odd, Selected(Vec<u32>)
    },
    Compress {
        input_pdf: PathBuf,
        mode: CompressionPreset, // Lossless, Balanced, Strong
    },
    TargetFileSize {
        input_pdf: PathBuf,
        target_size_bytes: u64,
        quality_priority: QualityPriority,
    },
    RemoveMetadata {
        input_pdf: PathBuf,
        strip_xmp: bool,
        strip_info_dict: bool,
    },
    SetPassword {
        input_pdf: PathBuf,
        user_password: String,
        owner_password: Option<String>,
    },
    Unlock {
        input_pdf: PathBuf,
        password: String,
    },
}
```

4. CRITICAL ALGORITHMS & IMPLEMENTATION REQUIREMENTS
======================================================================

4.1 Page Range Parser (Pure Rust Implementation):
Must parse human page strings ("1-5, 8, 11-14, 20") into a deduplicated, sorted list of zero-indexed or 1-indexed integers with strict bounds verification against total document page count.

4.2 Lossless Image Pass-Through for Images -> PDF:
When compiling JPEG images into a PDF:
- Do NOT decode and re-encode JPEGs via standard image buffers.
- Parse JPEG header directly to extract pixel dimensions, density, and color space (RGB/CMYK).
- Embed raw JPEG bytes into the PDF stream with `/Filter /DCTDecode`.
- Result: Lossless conversion, instant speed, minimal memory overhead.

4.3 Compression & Target Filesize Algorithm:
1. Stage 1 (Lossless): Run qpdf object stream optimization, duplicate stream unification, and unreferenced object purge.
2. Stage 2 (Assessment): If output <= target_size, finish immediately.
3. Stage 3 (Iterative Binary Search):
   - Extract embedded image streams.
   - Run a binary search over resolution (150-300 DPI) and JPEG quality (40-85%).
   - Re-pack PDF streams and measure file size on disk.
   - Settle on the highest visual quality candidate that respects `size <= target_size`.
   - Never apply full-page rasterization unless specifically requested by user.

4.4 Atomic File Writes:
```
Target File: /path/to/document_compressed.pdf
1. Create temporary file: /path/to/.document_compressed.pdf.tmp.[UUID]
2. Stream operations to temporary file.
3. Validate output integrity (e.g., qpdf verify / PDFium parse).
4. Perform atomic filesystem rename:
   std::fs::rename(temp_path, final_path)
5. On failure or cancellation, ensure immediate cleanup of temp_path.
```
